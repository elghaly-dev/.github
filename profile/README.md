## elghaly

Small open-source tools for people who run Solana bots and RPC nodes: status and slot-lag checks that say UNKNOWN when they can't tell.

🌐 [elghaly.dev](https://elghaly.dev)

### Public repos

| Repo | What it is | Page |
|------|------------|------|
| [glance](https://github.com/el-lghaly/glance) | Honest status layer for Solana bot operators. Rust and Python, pre-1.0, synthetic demo. | [glance.elghaly.dev](https://glance.elghaly.dev/) |
| [stale](https://github.com/el-lghaly/stale) | How many slots does your Solana RPC trail a reference endpoint? Read-only slot-lag checker and proxy in Go. | [stale.elghaly.dev](https://stale.elghaly.dev/) |
| [QUAY35](https://github.com/el-lghaly/QUAY35) | Source for the QUAY page: reports for Solana bot desks (static site, MIT). | [quay-35.elghaly.dev](https://quay-35.elghaly.dev/) |

Code is MIT (see each repo's LICENSE).
